# Список визуальных референсов

Владелец добавляет **18 PNG** из `pcbuilder.rar`; изображения **намеренно не входят** в ZIP стартовой структуры.

## Куда распаковывать

RAR содержит папку `pcbuilder/` на верхнем уровне. Распакуй `pcbuilder.rar` **в каталог**:

`D:\repos\WebDev\conigurable-pc-store\docs\references\`

Сохрани папку-обёртку из RAR. Получится, например:

`D:\repos\WebDev\conigurable-pc-store\docs\references\pcbuilder\registration.png`

При ручном копировании **только PNG** клади их прямо в `docs/references/pcbuilder/`.

## Точные имена и назначение

| Файл внутри `docs/references/pcbuilder/` | Дизайн-ориентир |
| --- | --- |
| `Header.png` | Header / раскрытый поиск, светлая тема |
| `полный хедер.png` | Общая композиция полного Header |
| `Хедер темный.png` | Тёмная версия Header/поиска |
| `main header black.png` | Тёмный референс Header и верхней композиции |
| `Витрина главная.png` | Главная / витрина |
| `Главаная с футером.png` | Главная с Footer (**опечатка — часть исходного имени**) |
| `main footer black.png` | Тёмный вариант общей композиции с Footer |
| `Футер.png` | Footer светлой темы |
| `каталог.png` | Каталог, закрытые фильтры |
| `католог с фильтрами.png` | Каталог, открытая панель фильтров (**исходная опечатка**) |
| `item page.png` | Страница товара |
| `cart.png` | Корзина, светлая тема |
| `корзина темная.png` | Корзина, тёмная тема |
| `конфигуратор.png` | 2D-конфигуратор |
| `профиль.png` | Личный кабинет |
| `registration.png` | Два состояния **одного** модального окна входа/регистрации |
| `Сборки.png` | Приватные сохранённые сборки |
| `Заказы.png` | Приватная история демонстрационных заказов |

**Исходные названия сохранены как есть, включая пробелы, кириллицу и опечатки.** Не нужно переименовывать файлы: на них ссылается манифест.

## Проверка

Из корня проекта выполнить:

```powershell
py scripts\verify_references.py
```

Программа читает `manifest.json`, проверяет присутствие, PNG-сигнатуру, размер и CRC32 исходных файлов из RAR. Она **только читает** файлы и ничего не изменяет. Пропущенные PNG выводятся по именам. До размещения референсов проверка ожидаемо возвращает неполный статус.

## Приоритет решений

Изображения — **визуальные**, а не функционально-архитектурные спецификации. При конфликте с утверждёнными правилами смотреть `.agent/PROJECT.md`, `docs/PRODUCT_REQUIREMENTS.md`, `docs/UI_SPEC.md`. Не реализовывать устаревшее сравнение товаров, 3D и checkout только потому, что оно показано на картинке.
